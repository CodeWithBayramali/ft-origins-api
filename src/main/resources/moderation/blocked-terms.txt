# Moderation blocklist for public user-chosen names: team names, usernames (the name on the pitch) and
# display names. One term per line; a line starting with '#' is a comment, blank lines are ignored.
#
# Terms are compared against a CANONICAL form of the name (see ProfanityFilter): Turkish-lowercased,
# accents and leetspeak folded, repeated letters squashed. So list each term ONCE, plainly: "siktir"
# already covers "S1KT1R", "s.i.k.t.i.r", "siiiktir" and "SİKTİR".
#
# Two kinds of term:
#   root   - a plain line. An unambiguous stem, caught inside a word ("Siktirgit") or spread over the
#            words from the start of one ("oro spu").
#   =word  - a line starting with '='. A short or ambiguous term, caught only as a WHOLE word, because it
#            hides inside innocent words: "sik" in Işık and bisiklet, "cock" in Hitchcock, "sex" in Essex.
# Before adding a root, make sure it is not inside a real name or place (the "Scunthorpe problem": "amkoy"
# would block Çamköy, "rapist" therapist); if it is, add it as a =word. A double letter counts: "yarrak"
# does not match "yarak" (kayarak), "nigger" does not match Niger.
#
# Deliberately left out: ethnic and national names, political terms, mild insults that are also everyday
# words, and words that are names or common words elsewhere: "mal" (Malatya), "am" (Frankfurt am Main,
# "I am"), "amina" (the name Amina).
#
# The file is read once at startup: add terms, then restart.
